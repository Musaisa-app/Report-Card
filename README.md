# Abu-Ashraf - Nigerian VTU Fintech Platform

A production-ready digital vending platform for buying and reselling airtime, internet data, electricity tokens, cable TV subscriptions, and other digital services in Nigeria.

## 🎯 Business Objective

Abu-Ashraf enables remote business operators to:
- Sell airtime, data, and digital services automatically
- Manage customers and agents
- Maintain digital wallets
- Generate profit from transaction markups
- Monitor business performance in real-time

## 📊 Technology Stack

### Frontend
- React 18+ with TypeScript
- Tailwind CSS for styling
- Mobile-first responsive design
- PWA support

### Backend
- ASP.NET Core 8 Web API
- Clean Architecture
- PostgreSQL database
- JWT authentication
- Repository Pattern

### Mobile
- Flutter for cross-platform support
